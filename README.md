# 🎮・FVREVER LAUNCHER

### Tu experiencia, a tu manera.

**FVREVER Launcher** es un launcher personalizado desarrollado para ofrecer una experiencia cómoda, sencilla y optimizada.

### ✨ Características
- 🚀 Inicio rápido y rendimiento optimizado.
- 🎨 Interfaz personalizada y agradable.
- ⚙️ Funcionalidades diseñadas para facilitar su uso.
- 📦 Registro de instalaciones y versiones.
- 🌱 Mejoras y optimizaciones constantes.

El objetivo es ofrecer una experiencia fluida y seguir mejorando el launcher con el tiempo.

# 📊・FVREVER ANALYTICS

### El crecimiento del proyecto, en un solo lugar.

**FVREVER Analytics** es el dashboard complementario de FVREVER Launcher. Permite visualizar estadísticas generales sobre las instalaciones y la actividad del proyecto.

### 📈 Estadísticas
- 📥 Total de instalaciones.
- 👥 Instalaciones activas hoy.
- 🚀 Cantidad de inicios del launcher.
- 🌍 Distribución aproximada por países.
- 🏷️ Distribución de versiones.
- 📊 Estadísticas y eventos de actividad.

# 🔐・PRIVACIDAD

La privacidad es importante para FVREVER.

- Se utilizan identificadores aleatorios de instalación.
- No se necesita una cuenta personal para el registro de instalaciones.
- La información de país es aproximada y se resuelve desde el servidor.
- La IP no se incluye en el JSON de telemetría enviado por el cliente.
- Las estadísticas opcionales de uso se gestionan por separado.
